# Elma Online components

This Storybook is a workshop for the UI components used on [elma.online](https://elma.online). Each component can be viewed and tested on its own, without running the API or the rest of the site.

- Browse components in the sidebar, grouped by category (Input, Layout, Data, …).
- Use the **Controls** panel below a story to change props live.
- Switch between site themes with the theme picker in the toolbar.

Stories live in `web/src/stories` as `*.stories.jsx` files. Add one when you create or change a component.
